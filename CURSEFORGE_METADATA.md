# 🇬🇧 English

The hilarious and chaotic newsroom from Element Animation's iconic **Villager News** series is now fully playable in Minecraft Java Edition!

### ✨ Key Features
- 🎙️ **Authentic Villager Reporters & Anchors**: Rendered with faithful Bedrock 3D geometry and dynamic Molang-driven facial and body animations.
- 🗣️ **Over 2,200 Spoken Voice Lines**: Full original English dialogue lines, plus complete brand-new Brazilian Portuguese (PT-BR) voice synthesis.
- 📰 **In-Game Reporter's Guide**: Interactive guidebook with custom graphical interface and in-game bilingual language selection.
- 🎩 **Cosmetic Items & Gear**: Handheld reporter microphone (with customized 1st and 3rd person holding poses), Mayor's Hat, Mustache, Testificate Helmet, and Detachable Villager Nose.
- ⚡ **Multiplayer Ready**: Complete client-server networking support for Minecraft Forge 1.20.1.

### 📦 Installation
1. Install **[Minecraft Forge 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)** (build 47.4.10+ recommended).
2. Download the `.jar` file and place it inside your `.minecraft/mods` folder.
3. Launch Minecraft with the Forge profile and enjoy!

# 🇧🇷 Português do Brasil

A redação de telejornal mais caótica e divertida da série **Villager News** de Element Animation agora está disponível no Minecraft Java Edition!

### ✨ Principais Recursos

- 🗣️ **Mais de 2.200 Linhas de Áudio Falado**: Dublagem original em Inglês e localização completa e inédita com vozes em **Português Brasileiro (PT-BR)**.
- 📰 **Manual do Repórter In-Game**: Livro interativo com interface customizada e alternância de idiomas diretamente no jogo.
